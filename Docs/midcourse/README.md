# Mid-Course Documentation

This directory contains the evidence required for the mandatory Task Tracker checkpoint.

## Submit these required files

- `user-stories.md`
- `mini-adr.md`
- `prompt-log.md`
- `verification.md`
- `reflection.md`

## Supporting files

- `assignment-roadmap.md`: plain-language interpretation and execution order.
- `behavior-contract.md`: observable behavior checked before and after refactoring.
- `claude-prompts.md`: one-at-a-time Claude Code prompt sequence.
- `submission-checklist.md`: final Met/Not Met readiness review.
- `evidence/README.md`: naming convention for optional screenshots and saved outputs.

## Important

Several fields are intentionally marked `TBD`, `NOT RUN`, or `[REPLACE ...]`. Replace them only with real evidence from the repository, terminal, browser, DevTools, Git, or Claude session. Do not submit invented results or leave bracketed placeholders in the final branch.
