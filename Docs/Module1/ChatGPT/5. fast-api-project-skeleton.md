from datetime import datetime, timezone
from fastapi import APIRouter, status
router = APIRouter(tags=["Health"])
@router.get("/health", status_code=status.HTTP_200_OK)
def get_health() -> dict[str, str]:
    """Return a simple service health response."""
    return {
        "status": "ok",
        "timestamp": datetime.now(timezone.utc).isoformat().replace("+00:00", "Z"),
    }

from datetime import datetime, timezone
from fastapi.testclient import TestClient
from app.main import app
client = TestClient(app)
def test_get_health_returns_200_with_status_and_utc_timestamp() -> None:
    response = client.get("/health")
    assert response.status_code == 200
    body = response.json()
    assert body["status"] == "ok"
    assert "timestamp" in body
    parsed_timestamp = datetime.fromisoformat(
        body["timestamp"].replace("Z", "+00:00")
    )
    assert parsed_timestamp.tzinfo is not None
    assert parsed_timestamp.utcoffset() == timezone.utc.utcoffset(parsed_timestamp)

README.md

# Task Tracker API
A minimal FastAPI project skeleton for Module 1 of the Task Tracker REST API learning project.
## Current Module 1 scope
This module includes:
- A locally runnable FastAPI app.
- `GET /health` returning HTTP 200.
- A health response with `status` and a UTC ISO 8601 `timestamp`.
- Swagger API docs at `/docs`.
- A small modular folder structure.
- A pytest test for the health endpoint.
This module does not include:
- Task CRUD.
- Task storage.
- Database setup.
- Authentication.
- User accounts.
- Docker.
- Deployment.
- Frontend files.
The final project may later support tasks with `id`, `title`, `description`, `status`, `priority`, and `assignee`.

Setup

Create and activate a virtual environment.

macOS/Linux:

python -m venv .venv
source .venv/bin/activate

Windows PowerShell:

python -m venv .venv
.\.venv\Scripts\Activate.ps1

Install dependencies:

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Run tests

python -m pytest

Start the server

python -m uvicorn app.main:app --reload

The app should start at:

http://127.0.0.1:8000

Verify the health endpoint

In another terminal, run:

curl -i http://127.0.0.1:8000/health

Expected status:

HTTP/1.1 200 OK

Example JSON response:

{
  "status": "ok",
  "timestamp": "2026-07-05T12:00:00.000000Z"
}

The timestamp value will be generated at request time.

Open Swagger docs

Open this URL in a browser:

http://127.0.0.1:8000/docs

Or run:

python -m webbrowser -t http://127.0.0.1:8000/docs
